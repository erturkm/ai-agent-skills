Installing a skill

Clone the repo and copy any skill folder into your agent's skills directory. These work with GitHub Copilot CLI and Microsoft Scout.

git clone https://github.com/erturkm/ai-agent-skills.git
cp -R ai-agent-skills/skills/copilot-mcp-app ~/.copilot/m-skills/

Then invoke it in your agent with /copilot-mcp-app, or just describe your task — skills match on their description automatically.

Skills are instruction sets, not executable code. Review before running anything against a production tenant. · github.com/erturkm/ai-agent-skills
